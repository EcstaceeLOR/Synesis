Guardrails for the presenter

  • Always name the visible environment: DEMO / NO VALUE or LIVE / BASE MAINNET.
  • Use “simulated” for demo responses. Use “executed” only with a verified live receipt.
  • Never present seeded IDs, balances, or PRF-1041 as evidence of a new live hackathon transaction.
  • If a live dependency fails, show the failure honestly and continue with the deterministic demo path.
