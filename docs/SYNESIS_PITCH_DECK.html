Why KeeperHubThe execution authority

KeeperHub is not a badge. It is the only path that can move value.

Olas triggers KeeperHub

Confirmed Mech delivery events trigger a saved KeeperHub workflow that sends a signed, replay-protected webhook into Synesis.

  • Live external project trigger
  • Onchain request and delivery correlation
  • Idempotent event inbox

Synesis consumes KeeperHub

Every approval and Aave supply is simulated and executed by the KeeperHub organization wallet using stable economic idempotency keys.

  • Exact simulation-to-broadcast hash binding
  • Target, selector, chain, and amount allowlists
  • Verified receipt plus independent Base confirmation

KeeperHub executes the value movement that Olas intelligence unlocks—and Synesis makes the reason independently verifiable.
